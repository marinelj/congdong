Pathway

Pathway

体育生升学规划

篮球项目，覆盖小升初、初升高两个升学阶段。

  1. Stage 01

    小升初

    以进入篮球传统校为目标。

  2. Stage 02

    初升高

    让篮球成为升学与成长的新路径

    根据学生的学业基础、篮球水平和发展目标，制定有针对性的训练与升学方案。

初升高 · 三个发展方向

  • Path A

    争取高中入学机会

    适合
    文化课升学压力较大的学生
    方式
    篮球特长训练结合升学指导，为升入高中多争取一条路

  • Path B

    冲刺篮球传统学校

    适合
    希望进入篮球传统学校、目前水平尚有差距的学生
    方式
    针对差距开展专项提升，为传统学校的选拔做好准备

  • Path C

    进阶运动员等级认证

    适合
    已在篮球传统学校校队训练的学生
    方式
    以国家一级或二级运动员为目标，规划训练与参赛路径

以上均为发展目标，不代表升学或等级认证结果的承诺。

每位学生的情况不同，具体方案请咨询贺老师。
