Pathway

Pathway

スポーツ進学プランニング

バスケットボールで、小学校から中学校、中学校から高校への2つの進学段階をサポートします。

  1. Stage 01

    小学校 → 中学校

    バスケットボール伝統校への進学を目指します。

  2. Stage 02

    中学校 → 高校

    バスケットボールを、進学と成長の新しい道に

    学業の基礎、バスケットボールのレベル、目標に合わせて、一人ひとりに合ったトレーニングと進学プランを作ります。

中学校 → 高校・3つの方向性

  • Path A

    高校進学の機会をつかむ

    対象
    学力試験での進学に不安がある生徒
    方法
    バスケットボールの専門トレーニングと進学指導を組み合わせ、高校進学への道をもう一つ増やします

  • Path B

    バスケットボール伝統校に挑む

    対象
    伝統校への進学を希望しているものの、現時点ではレベルに差がある生徒
    方法
    足りない部分を重点的に強化し、伝統校の選考に備えます

  • Path C

    運動員等級認定へステップアップ

    対象
    すでにバスケットボール伝統校のチームで練習している生徒
    方法
    中国の国家一級・二級運動員を目標に、トレーニングと大会出場の計画を立てます

いずれも育成上の目標であり、進学や等級認定の結果を約束するものではありません。

生徒一人ひとり状況は異なります。具体的なプランは賀先生にご相談ください。
